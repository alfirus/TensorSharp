TensorAgent 桌面版

运行在 Mac 或 Windows 电脑上的本地 AI 应用。安装应用，在模型页面下载一个模型，即可开始对话。你还可以处理照片与文件、生成图片，或使用技能创建文件和运行代码。可用功能取决于模型能力与电脑内存。

下载 macOS 版 ↗ 下载 Windows 版 ↗ 设置第一个模型 ↓

两个下载按钮均打开官方 Release 的 Assets（发行文件）列表。按下文选择适合平台的 tensoragent-desktop- 文件。桌面安装包由更新后的 Release Binaries 工作流生成；旧发行版可能只有 CLI/Server 归档。若最新发行版尚无桌面文件，请查看全部发行版，或在桌面发行版发布前按 源码构建说明运行。

本页按当前源码说明。个人知识库与回答引导在 v2026.10.10 后合入；下载的包须来自包含这些功能的新构建。模型条目可用性与运行验证见下文。

1 · 检查电脑配置

平台要求选择的版本
macOSApple Silicon（M 系列），macOS 14 或更新版本；包含 Metal 加速。发行包不提供 Intel Mac 版。osx-arm64
Windows CPUx64 电脑，Windows 10 1809（内部版本 17763）或更新版本 / Windows 11；无需 NVIDIA 显卡。win-x64-cpu
Windows NVIDIA相同的 Windows 要求，另需支持 CUDA 的 NVIDIA 显卡，以及兼容发行包 CUDA 运行时的驱动；具体 CUDA 版本见该发行版说明。win-x64-cuda

发行包包含 .NET 运行时和原生推理库；安装时无需 .NET SDK、Visual Studio、Xcode 或 CUDA Toolkit。Windows 还需要 Microsoft Edge WebView2 Evergreen Runtime，若系统没有则需安装。CUDA 发行包包含用户态 CUDA 库，但 NVIDIA 驱动需要单独安装。

最小的目录模型要求至少 12 GB 系统内存档位；除应用外，还应为模型文件预留数 GB 磁盘空间。模型页面会在下载前显示下载大小与内存要求。图片生成需要 24 GB 档位，大型文本和视频模型需要 32–48 GB。这是按系统内存判断的目录资格检查，Windows 也是如此；并不保证模型适配显卡显存或在每种后端都能运行。第一次可以选择下载量较小的 Gemma 4 E2B。

2 · 选择发行包

在 Release 的 Assets 中，下表的 V 代表去掉开头 v 的版本号。下载一个安装包和对应的校验和文件。

平台文件名用途
Mactensoragent-desktop-V-osx-arm64.dmg将应用拖入 Applications（应用程序）；通常选择此方式。
Mactensoragent-desktop-V-osx-arm64.pkg使用 macOS 安装器安装到 Applications。
Mactensoragent-desktop-V-osx-arm64.zip解压应用，复制到 Applications 或个人 Applications 文件夹。
Windowstensoragent-desktop-V-win-x64-cpu.msi
tensoragent-desktop-V-win-x64-cuda.msi		为当前用户安装，并添加开始菜单快捷方式。
Windowstensoragent-desktop-V-win-x64-cpu.zip
tensoragent-desktop-V-win-x64-cuda.zip		完整解压文件夹，无需安装器即可启动。

校验文件分别是 SHA256SUMS-tensoragent-desktop-V-osx-arm64.txt、SHA256SUMS-tensoragent-desktop-V-win-x64-cpu.txt 或 SHA256SUMS-tensoragent-desktop-V-win-x64-cuda.txt。把下面的 V 和文件名换成下载的版本与格式，再将输出的哈希与校验文件中该文件对应的一行比较：

# macOS 终端，在下载文件夹中
cd ~/Downloads
shasum -a 256 tensoragent-desktop-V-osx-arm64.dmg
# Windows PowerShell，在下载文件夹中
Set-Location "$env:USERPROFILE\Downloads"
Get-FileHash .\tensoragent-desktop-V-win-x64-cpu.msi -Algorithm SHA256

若哈希不同，请重新下载后再安装。校验和验证文件内容，不会给未签名的文件添加签名。发行版说明会注明是否签名或公证。默认情况下，Mac 应用仅作 ad hoc 签名、未经公证，Windows 发行包未签名。

3a · 在 macOS 安装

  1. 安装应用

    DMG：打开磁盘映像，将 TensorAgent.app 拖入 Applications（应用程序），然后推出磁盘映像。PKG：打开安装包并按安装器步骤操作；安装到 /Applications 可能需要管理员密码。ZIP：解压后，将应用移至 /Applications，或放入 ~/Applications，仅供当前账户使用。

  2. 打开 TensorAgent

    从应用程序文件夹启动已安装的副本。对于未经公证的发行包，macOS 可能阻止第一次启动或安装。尝试打开后，在系统设置 → 隐私与安全性 → 仍要打开中为已经确认来源与校验和的文件作例外，并确认提示。若提示不同，参考 Apple 关于打开下载应用的说明。

  3. 允许需要的权限

    照片、相机、麦克风或语音权限会在使用对应功能时请求。之后可在系统设置 → 隐私与安全性中检查。普通文字聊天不需要相机或麦克风权限。

3b · 在 Windows 安装

  1. 选择 CPU 或 CUDA

    没有兼容的 NVIDIA 显卡，或希望避免配置 GPU 驱动时，选择 CPU。有 NVIDIA 显卡和兼容驱动时，选择 CUDA。同一时间只安装一种版本；两种 MSI 属于同一个升级系列。

  2. 安装或解压

    MSI：打开并按安装器步骤操作。默认安装到当前用户的 %LOCALAPPDATA%\Programs\TensorAgent，添加开始菜单入口，无需管理员权限。ZIP：右键 → 全部解压缩，解压到可写的文件夹，再打开 TensorAgent.Maui.exe。DLL、webui 与 skills 文件夹必须与程序保持在一起；不要在 ZIP 内直接运行。

  3. 启动应用

    从开始菜单打开 TensorAgent，或启动解压后的程序。未签名的发行包可能触发 Microsoft Defender SmartScreen；先核对来源和校验和，再在系统策略允许时选择更多信息 → 仍要运行。受管理电脑没有该选项时，请联系管理员。

若提示缺少 WebView2，或聊天区域未显示，请安装 Evergreen Runtime，再重新打开 TensorAgent。

4 · 下载模型并发送第一条消息

  1. 选择语言与存储位置

    打开应用菜单 → 设置。语言 → 应用语言默认跟随系统，可选八种语言。在存储 → 模型下载和缓存文件夹中输入空间足够的磁盘上的绝对路径，选择保存文件夹。更改此设置不会移动已经下载的文件。

  2. 打开模型页面

    在空白聊天中选择选择模型，或菜单 → 模型。选择 Gemma 4 E2B 并点击下载。先阅读显示的模型许可证、下载量和内存要求。灰色的过大条目无法在当前设备加载。

  3. 等待校验与加载

    进度行显示下载和验证，传输中断后可以继续。在模型页面保持选中的下载会在完成后加载；若离开了该页面，请返回并选择使用。等模型显示正在使用后再发消息。无需另起服务器或输入 API 密钥。

  4. 试一次简单对话

    回到聊天，发送“给我三个周末项目的点子。”按 Enter 发送，按 Shift+Enter 换行。点击停止取消回答。菜单中列出已保存的聊天，换话题时可以新建聊天；应用重启后会话仍然保留。

推理在本机运行。首次下载模型需要联网；必要文件齐全后，普通聊天可以离线使用。允许访问网络控制模型运行的代码与软件包安装，不会阻止应用下载你主动请求的模型。

浏览模型目录

当前目录有 38 个条目，可按模型名称、家族、量化或输入能力搜索，并使用全部、兼容、已下载筛选；家族分组可展开，正在下载的条目保持可见。新增条目包括较大的 Gemma/Qwen、GPT OSS、Nemotron、Mistral、Hunyuan、DiffusionGemma、DeepSeek 与 GLM 检查点；许多仍标为实验性。条目有固定版本下载与哈希校验，但目录元数据检查不等于在每台设备上完成推理验证。以条目显示的系统内存档位、输入能力与模型卡为准；较大条目可能需要远超普通电脑的内存。

生成时引导回答

回答尚未完成时，可在输入框输入并发送新的指令。当前生成会中断，已经产生的回答保留在聊天中，然后按新指令生成；宿主先等待旧生成清理完成。输入框为空时，发送按钮显示停止；有新内容时显示引导操作。引导不能撤销已经执行的工具动作。

5 · 使用照片、文件、图片和视频

  • 询问照片或文件：选择 + → 照片或文件，附上内容，并说明需求。加载的模型必须支持该输入。视觉模型缺少可选投影器时，选择模型 → 添加视觉，完成后点击启用视觉。设置 → 下载 → 包含可选文件会在后续下载中包含投影器及可用的草稿头。
  • 生成图片：加载 Qwen-Image 2.1 或 Qwen-Image 2.1 Turbo 后描述图片。Turbo 使用固定 8 步、CFG 1 配方，AD-Q4_K 为 24 GB 档位，Q8_0 为 32 GB 档位，并复用基础版的编码器/VAE 文件；它不接受步数蒸馏 LoRA。编辑照片时附上照片并说明修改；缩略图旁的选择区域可涂选要改的部分。完成后可比较原图或再次编辑。模型 → LoRA 插件可另行下载兼容插件：基础版共十四个，Turbo 为四个风格/编辑插件。见图片编辑指南。
  • 生成视频：加载适用的 MiniMax-H3 目录条目，描述短视频，并使用该条目支持的附件。视频需要 GPU 后端，CPU 发行包没有视频回退路径。已记录的 Windows 桌面应用验证不包含音视频生成。见视频模型要求与限制。
  • 保留结果：打开生成文件的链接，保存或复制到自己的文件夹。聊天保留文字记录，但生成文件和上传附件位于应用缓存；清理缓存或移除应用前，请另存重要文件。

让资料库供聊天复用

打开菜单 → 知识库创建集合，上传文件或递归文件夹，也可添加聊天保存已有对话与可用附件。查看提取状态，勾选在此聊天中使用 {集合}后再提问；浏览集合不会自动选中。新聊天默认不选集合。回答中的检索来源链接可打开引用位置与原文件。见知识库指南了解 OCR、支持格式、媒体模型要求与限制。

6 · 配置代码和浏览器工作

文字聊天无需额外开发工具。桌面代码技能使用电脑上安装的程序：Python 任务需要 Python 3，JavaScript 或内置 Playwright 浏览器技能需要 Node.js 与 npm。浏览器技能要求 Node.js 20 或更新版本。使程序可通过 PATH 找到，然后完全退出并重新打开 TensorAgent。Windows 应使用原生 Windows Node/npm，而非 WSL 中的版本。

设置 → 沙盒如何选择
运行代码允许执行命令和技能脚本；在 macOS 上，进程在系统沙盒约束下使用聊天工作区。仅聊天时可以关闭。
不使用沙盒运行（Windows）默认关闭。它和运行代码都开启时，才允许运行命令。Windows 无法隔离进程的文件或网络访问，程序可访问账户有权访问的内容；接受这一权限范围后才开启。
允许访问网络默认关闭；浏览器任务与安装代码依赖需要开启。Windows 中未受隔离的程序并不会被此开关隔离。
子代理默认开启；允许同一本地模型运行辅助代理。关闭可避免额外辅助会话及其内存开销。

使用支持工具的聊天模型，尝试“把这些开销整理成 CSV，用 Python 检查合计。”应直接附上输入文件，而不是期待 Mac 沙盒命令读取无关文件夹。浏览器任务需要启用相应设置，然后可以说“使用 Playwright 技能访问 example.com 并总结页面。”首次使用可能下载 npm 软件包与浏览器。自动化浏览器使用独立会话，不会继承日常浏览器的登录状态。见浏览器配置与技能限制。

7 · 更新、备份或卸载

更新：退出 TensorAgent，从最新发行版下载匹配平台的新版，校验后重新安装。Mac 替换应用程序文件夹中的应用；Windows 运行新的 MSI；ZIP 版请解压到新文件夹并使用新副本。更新由用户手动执行。模型、设置和聊天存储在安装目录之外。

平台设置与聊天：请备份这里默认模型、上传与生成文件
macOS~/Library/Application Support/TensorAgent~/Library/Caches/TensorAgent
Windows%LOCALAPPDATA%\TensorAgent\Data%LOCALAPPDATA%\TensorAgent\Cache

复制文件夹前请退出应用。若设置了自定义模型文件夹，请另外备份或复用该目录；Mac 备份工具可能不包含 Caches。更改模型文件夹不会移动旧文件；若希望复用，等下载完成并关闭应用后，手动移动对应的模型子文件夹。

卸载：Mac 将 TensorAgent.app 移到废纸篓，PKG 安装没有单独卸载器。Windows 的 MSI 安装使用设置 → 应用 → 已安装的应用 → TensorAgent → 卸载；ZIP 版删除解压后的程序文件夹。移除应用会保留用户数据与模型以便重新安装。清理单个模型用模型 → 删除，清理历史用设置 → 存储 → 删除所有聊天。若要完全移除，请先备份并退出，再删除上表的数据与缓存文件夹，以及不再需要的自定义模型文件夹。

知识库位于数据文件夹内的 knowledge，与模型/上传缓存分开；它保留导入原文件。备份时退出应用并复制数据文件夹。删除聊天或上传缓存不会删除已导入知识来源；删除集合/文档需要界面内的第二次确认。

故障排查

问题处理方式
发行版没有桌面下载展开 Assets，查找 tensoragent-desktop-。旧 CLI/Server ZIP 不会安装 TensorAgent；选择有桌面文件的发行版或从源码构建。
Windows 无法启动或聊天区域空白安装 WebView2，确保 ZIP 全部文件完整解压在一起，检查该发行包支持的 Windows 版本与架构；校验和不符则重新下载。
CUDA 加载报错或 GPU 不兼容按发行包 CUDA 版本检查 NVIDIA 驱动；没有兼容 NVIDIA GPU 时使用 CPU 版，速度会较慢。不要在 CPU/CUDA 包之间复制 DLL。
模型显示过大或加载时内存不足选择较小的目录模型，关闭占内存的程序，分别检查系统内存与空闲显存。满足系统内存资格的模型仍可能超过 GPU 容量。
下载中断或验证失败检查磁盘空间与网络，回到模型页面选择继续或重试。更改模型文件夹前等待下载或导入完成。
模型看不到照片检查支持的输入，下载添加视觉并点击启用视觉；加载正确模型后重新附上照片。
代码或浏览器任务被拒绝检查运行代码、Windows 不使用沙盒运行，以及需要时的允许访问网络；为任务安装 Python 或原生 Node/npm，重开应用并查看工具报告的错误。
回复显示被截断增加设置 → 生成 → 回复输出上限，或新建聊天并缩短提示词；这调整回复长度，不改变模型上下文窗口。

报告问题时，请在 GitHub issue 中提供发行版本、包类型、系统、内存/GPU、模型与准确错误。日志位于缓存下的 logs 文件夹；分享前请检查，其中可能含本地路径或提示词。

验证范围：发行构建与包检查并不证明所有模型、GPU、权限提示或安装路径都通过验证。已记录的 Windows 桌面检查覆盖特定聊天、文件、代码工具、合成视觉、取消与会话恢复；目录下载、原生选择器、音视频生成及长时间运行被排除。Mac 运行覆盖特定 Apple Silicon 模型与工作流。确切设备和模型覆盖见 TensorAgent README；不可用或跳过的场景不算验证通过。
